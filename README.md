# Features
- Deadline tracker
    - create deadlines
    - change deadline statuses between not started, in progress, and done
    - filter/search deadlines by course, progress, or due date
    - edit and delete deadlines
    - change deadline view from list to board view
- Calendar
    - view deadlines on a familiar calendar interface
    - create deadlines to be displayed on calendar
    - edit and delete deadlines
- Study Tracker
    - track study sessions
    - create stopwatch or countdown study trackers
    - view session history for each tracker
    - choose whether to log specific sessions
- Progress Report
    - track progress on course deadlines
    - track study time committed
    - view upcoming deadlines

# Technologies Used

- HTML5 - App structure
- CSS3 - Styling, Layout
- JavaScript - App functionality and logic
